## 2. 表结构设计

### 2.1 users 表 — 用户表

```sql
CREATE TABLE users (
    id           INT AUTO_INCREMENT PRIMARY KEY,
    username     VARCHAR(255) NOT NULL UNIQUE,
    password     VARCHAR(255) NOT NULL,
    role         VARCHAR(50)  NOT NULL,          -- ADMIN / TEACHER / STUDENT
    email        VARCHAR(255) UNIQUE,
    status       INT,                            -- 1=启用, 0=禁用
    created_time DATETIME,
    updated_time DATETIME
);
```

### 2.2 students 表 — 学生表

```sql
CREATE TABLE students (
    id             INT AUTO_INCREMENT PRIMARY KEY,
    user_id        INT NOT NULL UNIQUE,           -- 关联 users.id
    name           VARCHAR(255) NOT NULL,
    grade          INT,
    major          VARCHAR(255),
    class_name     VARCHAR(255),
    dormitory      VARCHAR(255),
    guardian_phone VARCHAR(255),
    created_at     DATETIME,
    updated_at     DATETIME
);
```

### 2.3 teachers 表 — 教师表

```sql
CREATE TABLE teachers (
    id             INT AUTO_INCREMENT PRIMARY KEY,
    user_id        INT NOT NULL UNIQUE,            -- 关联 users.id
    name           VARCHAR(255) NOT NULL,
    department     VARCHAR(255),
    title          VARCHAR(255),
    research_field VARCHAR(255),
    office_address VARCHAR(255),
    created_at     DATETIME,
    updated_at     DATETIME
);
```

### 2.4 courses 表 — 课程表

```sql
CREATE TABLE courses (
    id          INT AUTO_INCREMENT PRIMARY KEY,
    course_name VARCHAR(255) NOT NULL,
    teacher_id  INT,                               -- 关联 teachers.id
    credit      DECIMAL(10,2),
    begin_date  DATE,
    end_date    DATE,
    schedule    VARCHAR(255),
    description TEXT,
    created_at  DATETIME,
    updated_at  DATETIME
);
```

### 2.5 grades 表 — 成绩表

```sql
CREATE TABLE grades (
    id         INT AUTO_INCREMENT PRIMARY KEY,
    student_id INT NOT NULL,                        -- 关联 students.id
    course_id  INT NOT NULL,                        -- 关联 courses.id
    score      DECIMAL(10,2),
    semester   INT,
    created_at DATETIME,
    updated_at DATETIME
);
```

### 2.6 operation_logs 表 — 操作日志表

```sql
CREATE TABLE operation_logs (
    id         INT AUTO_INCREMENT PRIMARY KEY,
    operator   VARCHAR(255) NOT NULL,
    action     VARCHAR(255) NOT NULL,
    created_at DATETIME
);
```

### 2.7 conversations 表 — 对话会话表

```sql
CREATE TABLE conversations (
    id               BIGINT AUTO_INCREMENT PRIMARY KEY,
    conversation_uid VARCHAR(255) UNIQUE,
    type             VARCHAR(50),                  -- chat / rag
    updated_time     DATETIME
);
```

### 2.8 Spring AI 消息表（自动管理）

Spring AI JDBC ChatMemoryRepository 自动管理 `messages` 相关表。

## 3. ER 关系图

```
users ──1:1──→ students   (user_id UNIQUE)
users ──1:1──→ teachers   (user_id UNIQUE)
teachers ──1:N──→ courses  (teacher_id)
students ──M:N──→ courses  (通过 grades 关联)
grades.student_id → students.id
grades.course_id  → courses.id
```
