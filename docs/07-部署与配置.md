# 部署与配置文档

## 1. 环境要求

| 组件 | 版本/要求 |
|------|----------|
| JDK | 17+ |
| Maven | 3.x |
| MySQL | 5.7+ / 8.x |
| Redis | 6.x+（需支持向量搜索模块 RedisSearch） |
| 阿里云 OSS | cn-beijing 地域 |

## 2. 配置文件 (application.yml)

### 2.1 服务端口
```yaml
server:
  port: 8081
```

### 2.2 数据库
```yaml
spring:
  datasource:
    url: jdbc:mysql://<HOST>:<PORT>/ai
    driver-class-name: com.mysql.cj.jdbc.Driver
    username: <USERNAME>
    password: <PASSWORD>
```

### 2.3 Redis
```yaml
spring:
  data:
    redis:
      host: <REDIS_HOST>
      port: 6379
      password: <REDIS_PASSWORD>
```

### 2.4 AI 模型配置
```yaml
ai:
  platforms:
    - name: <平台名称>
      api-key: <API密钥>
      base-url: <基础URL>
      options:
        - model: <模型名称>
          temperature: 0.7
          max-tokens: 1024
```

### 2.5 阿里云 OSS
```yaml
aliyun:
  oss:
    endpoint: https://oss-cn-beijing.aliyuncs.com
    bucket: <BUCKET_NAME>
    region: cn-beijing
    access-key-id: <AK>         # 也可通过环境变量设置
    access-key-secret: <SK>
```

### 2.6 搜索引擎
```yaml
internet:
  websearch:
    searxng:
      url: <SEARXNG_URL>/search
      counts: 20
```

## 3. 启动步骤

```bash
# 1. 克隆项目
git clone <repo-url>

# 2. 配置 application.yml（填入实际的数据库、Redis、API 密钥等）

# 3. 初始化数据库（执行 SQL 脚本）
mysql -u <user> -p < src/main/resources/建表.sql
mysql -u <user> -p < src/main/resources/建表_会话记忆补充.sql

# 4. 启动 Redis（需安装 RedisSearch 模块）

# 5. 构建并运行
mvn clean package -DskipTests
java -jar target/ai-0.0.1-SNAPSHOT.jar
```

## 4. 访问地址

| 地址 | 说明 |
|------|------|
| `http://localhost:8081` | API 服务 |
| `http://localhost:8081/doc.html` | Knife4j API 文档 |
| `http://localhost:8081/swagger-ui.html` | Swagger UI |
| `http://localhost:8081/v3/api-docs` | OpenAPI JSON |

## 5. 日志配置

```yaml
logging:
  level:
    org.springframework.ai.chat.client.advisor: debug
    com.example.ai: debug
```

## 6. 文件上传限制

```yaml
spring:
  servlet:
    multipart:
      max-file-size: 10MB
      max-request-size: 10MB
```
