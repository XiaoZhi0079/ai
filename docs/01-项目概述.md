# java-ai 项目概述

## 1. 项目简介

`java-ai` 是一个基于 **Spring Boot 3.5.5** 和 **Spring AI 1.1.2** 构建的智能教务管理系统，采用 **Java 17**。该系统融合了 AI 对话能力与传统的校园教务管理（学生、教师、课程、成绩 CRUD），形成一个"AI + 教务"的一体化后端服务。

## 2. 核心功能

| 功能模块 | 说明 |
|---------|------|
| 🤖 多模型 AI 对话 | 支持通义千问、GLM、GPT、Kimi、DeepSeek 等多平台模型动态切换 |
| 📚 RAG 知识库问答 | 基于 Redis VectorStore + Tika 文档解析，支持上传文档后进行语义检索问答 |
| 🌐 联网搜索 | 集成 SearXNG 搜索引擎，实现实时网络搜索并结合 AI 生成回答 |
| 🖼️ AI 图片生成 | 集成阿里云通义万相模型 (`wan2.5-t2i-preview`)，支持文生图 |
| 👥 用户管理 | 注册/登录/JWT 鉴权，RBAC 三种角色（ADMIN / TEACHER / STUDENT） |
| 📖 教务 CRUD | 学生、教师、课程、成绩的完整增删改查 |
| 📁 文件上传 | 阿里云 OSS 对象存储，支持图片上传与 MIME 类型识别 |
| 📜 操作日志 | 所有关键操作（注册、登录、增删改）自动记录审计日志 |
| 💬 对话记忆 | 支持 JDBC 持久化的对话记忆，最多保留 50 条消息窗口 |

## 3. 技术栈

| 类别 | 技术 |
|------|------|
| 框架 | Spring Boot 3.5.5 |
| AI 框架 | Spring AI 1.1.2 |
| 语言 | Java 17 |
| 数据库 | MySQL（通过 MyBatis 注解映射） |
| 向量数据库 | Redis（Spring AI Redis VectorStore） |
| 对象存储 | 阿里云 OSS |
| 认证 | JWT（jjwt 0.9.1） + BCrypt 密码加密 |
| API 文档 | Knife4j / SpringDoc OpenAPI 3 |
| 搜索引擎 | SearXNG（自部署实例） |
| HTTP 客户端 | OkHttp 3 |
| 工具库 | Lombok、Hutool |
| 监控 | Spring Boot Actuator |
| 嵌入模型 | 通义 `text-embedding-v3` |
