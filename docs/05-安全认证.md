# 安全认证文档

## 1. 认证流程

### 1.1 注册流程

```
客户端 POST /auth/register
    │
    ▼
AuthController.register()
    │
    ├── 参数校验（用户名/密码非空）
    ├── 唯一性校验（用户名/邮箱不重复）
    ├── 角色权限校验（非 STUDENT 需 ADMIN 权限）
    ├── BCrypt 加密密码
    ├── 插入数据库
    └── 记录操作日志
    │
    ▼
返回 AuthResponse（不含 token）
```

### 1.2 登录流程

```
客户端 POST /auth/login
    │
    ▼
AuthController.login()
    │
    ├── 参数校验
    ├── 查询用户
    ├── 校验用户状态（status=1）
    ├── 密码匹配
    │   ├── BCrypt 密码 → passwordEncoder.matches()
    │   └── 明文密码 → equals() (兼容旧数据)
    ├── 生成 JWT Token（含 id、username、role）
    └── 记录操作日志
    │
    ▼
返回 AuthResponse（含 token，有效期 24 小时）
```

## 2. JWT 令牌

### 2.1 配置

| 参数 | 值 |
|------|---|
| 算法 | HS256 |
| 密钥 | `5ZSv54ix6YeM576O`（硬编码） |
| 有效期 | 86400000ms = 24 小时 |
| 库 | jjwt 0.9.1 |

### 2.2 Claims 结构

```json
{
  "id": 1,
  "username": "admin",
  "role": "ADMIN",
  "exp": 1710300000
}
```

### 2.3 JWT 拦截器

- 拦截路径：`/api/**`
- Token 来源：请求头 `token`
- 解析后注入请求属性：`authUserId`、`authUser`、`authRole`
- 失败返回 401

## 3. 角色权限控制 (RBAC)

### 3.1 角色定义

```java
public enum Role {
    ADMIN,     // 管理员：全部权限
    TEACHER,   // 教师：学生/课程/成绩管理
    STUDENT    // 学生：基础权限
}
```

### 3.2 权限注解

```java
@RoleRequired({Role.ADMIN, Role.TEACHER})  // 允许 ADMIN 和 TEACHER
@PostMapping
public LeeResult<Student> create(...) { ... }
```

### 3.3 权限矩阵

| 资源 | ADMIN | TEACHER | STUDENT |
|------|:-----:|:-------:|:-------:|
| 用户管理 | ✅ | ❌ | ❌ |
| 教师管理 | ✅ | ❌ | ❌ |
| 学生管理 | ✅ | ✅ | ❌ |
| 课程管理 | ✅ | ✅ | ❌ |
| 成绩管理 | ✅ | ✅ | ❌ |
| AI 对话 | ✅ | ✅ | ✅ |
| 文件上传 | ✅ | ✅ | ✅ |

### 3.4 角色拦截器

- 拦截路径：`/api/**`
- 角色来源优先级：
  1. `X-Role` 请求头
  2. JWT 解析的 `authRole` 属性
- 失败返回 403

## 4. 密码安全

- 加密算法：BCrypt（通过 `spring-security-crypto`）
- 兼容策略：支持 BCrypt 哈希密码和明文旧密码的双重校验
- 密码以 `$2a$`/`$2b$`/`$2y$` 开头时走 BCrypt 匹配
