# 登录页重设计方案

**目标**

将当前 `frontend/src/views/login/LoginView.vue` 重写为更美观、更专业的“学术科技风”登录页，在保留现有登录/注册功能、表单校验、路由跳转与 Element Plus 技术栈的前提下，显著提升视觉层次、品牌感与首屏体验。

**范围**

- 仅重设计前端登录页视觉与布局
- 保留现有登录/注册字段与交互逻辑
- 保留 Vue 3 + TypeScript + Element Plus 现有实现方式
- 不改动后端接口协议
- 不引入新的 UI 框架或远程静态资源

**非目标**

- 不重构认证状态管理
- 不新增第三方依赖
- 不修改注册字段定义与业务规则
- 不扩展忘记密码、验证码、SSO 等新功能

## 现状总结

当前登录页为单卡片居中布局，背景为紫色渐变，信息层次较少，品牌表达较弱。页面功能完整，但视觉风格较普通，与“校园知识问答助手”的平台定位不完全匹配。

已确认前端栈：

- `Vue 3`
- `TypeScript`
- `Element Plus`
- `Vite`

## 已确认设计方向

用户确认采用：**学术科技风 + 双栏门户型布局**。

核心定位：

- 专业
- 清爽
- 有校园平台气质
- 有一定科技感，但不过度炫技

## 设计方案

### 1. 页面结构

登录页改为左右双栏布局：

- 左栏为品牌展示区
- 右栏为登录/注册操作区

在桌面端使用双栏布局，在中小屏幕下降级为纵向堆叠布局，保证可用性。

### 2. 左栏：品牌展示区

左栏用于承载平台识别与价值说明，提升页面完成度。

包含内容：

- 平台主标题：`校园知识问答助手`
- 一行副标题：突出“知识问答、文档检索、数据查询”这类平台能力
- 3 个能力点模块，例如：
  - 校园文档智能问答
  - 教务数据自然语言查询
  - 多角色统一访问入口
- 弱装饰性科技背景：渐变、光晕、网格/径向高光等纯 CSS 装饰

视觉要求：

- 不使用俗艳紫色主背景
- 采用深蓝、靛青、青蓝、白色为主的学术科技配色
- 信息层次明显，左栏更像“平台介绍页”，而不是空白背景

### 3. 右栏：登录/注册卡片区

右栏保留现有登录/注册标签页切换，但整体升级为更精致的悬浮卡片。

卡片包含：

- 小型欢迎语或说明文字
- 登录/注册 tabs
- 输入框、选择框、按钮
- 辅助提示文案（如账号安全、教师注册密钥提示）

视觉要求：

- 白色或高透明浅色卡片
- 边框弱化，阴影柔和
- 适中圆角，不做过大的胶囊风
- 输入框与按钮风格统一
- 激活 tab、聚焦输入框、主按钮具有明确品牌色反馈

### 4. 配色系统

采用克制的学术科技风配色，避免泛滥的 AI 紫蓝风。

建议主色：

- 主背景深色：深蓝 / 靛蓝
- 强调色：青蓝
- 内容底色：白色 / 冷白
- 文本色：深灰蓝
- 辅助边框：低对比浅蓝灰

目标效果：

- 看起来像校园智能平台入口
- 有科技感但不浮夸
- 与管理后台、知识平台的气质兼容

### 5. 字体与信息层级

在不引入外部字体的前提下，沿用系统字体栈，重点通过字号、字重、间距建立层级：

- 大标题：稳重、清晰
- 副标题：简洁说明平台能力
- 能力点标题：短句化
- 表单标题与辅助说明：弱一级层级

避免：

- 大段冗长说明文字
- 过多装饰性英文
- 过强营销口吻

### 6. 交互与动效

本次只做轻量增强，不引入动画库。

允许的交互表现：

- 卡片轻微悬浮感
- 输入框聚焦态高亮
- 按钮 hover / active 反馈
- 标签切换视觉强化

不做：

- 大面积粒子动画
- 复杂视差
- 重型背景视频

### 7. 响应式策略

桌面端：

- 左右双栏
- 左栏展示品牌与能力点
- 右栏固定为主操作区

平板与移动端：

- 改为单列布局
- 左栏内容收敛到标题与简短说明
- 卡片宽度自适应，保证表单操作优先

### 8. 保留的业务行为

以下行为必须保持不变：

- 登录表单校验
- 注册表单校验
- 教师角色时展示注册密钥输入项
- 登录成功后跳转 `/dashboard`
- 注册成功后跳转 `/dashboard`
- 错误处理仍交由现有拦截器/消息机制

## 实施边界

预计主要修改文件：

- `frontend/src/views/login/LoginView.vue`

如需补充全局样式，仅在必要时评估是否修改：

- `frontend/src/App.vue`
- `frontend/src/main.ts`

默认优先在单文件组件内完成样式重构，避免扩大影响面。

## 验收标准

完成后应满足：

- 页面视觉明显优于现状
- 桌面端形成清晰的双栏结构
- 登录与注册流程均可正常使用
- 教师注册密钥字段逻辑不受影响
- 页面在常见宽度下不出现明显布局错乱
- 未引入新的依赖或远程资源

## 风险与控制

### 风险 1：样式升级影响 Element Plus 默认布局

控制方式：

- 尽量使用局部 class 包裹
- 避免粗暴覆盖全局 `.el-*` 样式

### 风险 2：双栏布局在小屏幕下拥挤

控制方式：

- 明确断点下切换为单列
- 收敛左侧文案长度与模块数量

### 风险 3：视觉增强过度导致“花哨”

控制方式：

- 坚持克制配色
- 只保留轻量科技感装饰
- 以可读性和专业感优先

## 结论

本次重设计将以“学术科技风双栏门户型登录页”为核心，保留现有认证流程与字段规则，只重做布局、视觉层次和交互质感。实现应聚焦于单文件组件内的结构与样式升级，以较小范围修改获得明显的首屏品质提升。
